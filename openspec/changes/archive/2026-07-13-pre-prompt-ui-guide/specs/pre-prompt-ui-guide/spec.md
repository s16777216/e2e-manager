## ADDED Requirements

### Requirement: Multi-level System Prompt Merging
The system SHALL retrieve and concatenate the `systemPrompt` from the Project, TestGroup(s), and Testcase in order of inheritance (`Project -> TestGroup -> Testcase`) to create a unified system prompt context during a TestRun.

#### Scenario: Successfully concatenate prompts from multiple levels
- **WHEN** a TestRun is initiated where the Project has systemPrompt `"A"`, the Group has `"B"`, and the Testcase has `"C"`
- **THEN** the system merges them using double newlines as delimiters, resulting in `"A\n\nB\n\nC"`

#### Scenario: Merge prompt with empty levels
- **WHEN** a TestRun is initiated where the Project has systemPrompt `"A"` but the Groups and Testcase have empty or null prompts
- **THEN** the system returns `"A"` without extra leading/trailing whitespace or empty delimiter segments

---

### Requirement: System Prompt Dynamic Variable Interpolation
The system SHALL interpolate variables and evaluate JS expressions inside `{{}}` within the merged system prompt using the current `RunContext` and merged variable values before feeding it to the AI Agent.

#### Scenario: Interpolate static variable and JS expression in prompt
- **WHEN** the merged system prompt is `"Base URL: {{baseUrl}} and Timestamp: {{Date.now()}}"` where `baseUrl` is `"https://example.com"`
- **THEN** the system interpolates the values and produces `"Base URL: https://example.com and Timestamp: <timestamp>"`

---

### Requirement: Inject custom prompt into AI Executor System Message
The system SHALL insert the interpolated merged system prompt under a designated section `# Page & UI Guide` in the AI Executor's system prompt message.

#### Scenario: Agent receives custom UI instructions
- **WHEN** the AI Executor node is evaluated with an interpolated system prompt `"All modal headers are H3."`
- **THEN** the resulting prompt generated by `buildExecutorSystemPrompt` contains a section `# Page & UI Guide\nAll modal headers are H3.`
