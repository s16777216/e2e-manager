## Context

目前的截圖檢視缺乏互動性，使用者無法直接在 UI 中放大檢視細節。這在使用多模態斷言分析失敗原因時影響了使用者的診斷效率。

## Goals / Non-Goals

**Goals:**
- 提供點擊圖片即可放大檢視的功能。
- 引入輕量化的圖片瀏覽器庫 `react-photo-view`。
- 建立共用的 `ImagePreview` 元件，提升截圖檢視體驗並保持專案一致性。

**Non-Goals:**
- 不會處理圖片上傳與伺服器端轉檔邏輯。
- 不會支援多圖同時檢視（暫時聚焦於單一圖片檢視）。

## Decisions

- **引入 `react-photo-view`**: 選擇此庫是因為其輕量、高效，且對 React 19 的相容性良好。相較於其他燈箱庫，它在 React 的整合上更為簡約。
- **封裝 `ImagePreview` 元件**: 將檢視器邏輯封裝在自訂元件中，而非直接在 UI 邏輯中內聯 `react-photo-view`，便於未來維護與擴充（如增加下載功能）。

## Risks / Trade-offs

- **依賴增加**: 雖然 `react-photo-view` 輕量，但仍增加了一個額外的依賴項。
- **UI 風格微調**: 需要確保該庫的預設樣式不會與現有的 `zinc-950` 深色風格衝突。如果衝突，需增加全域 CSS 覆蓋。
